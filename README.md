# 修辭小偵探｜翰林三上互動學習版

這是一個獨立的 GitHub Pages 靜態網站，不需要原本南一版網站或原作者儲存庫的權限。

## 主要功能

- 翰林版三年級上學期第 1～6 課。
- 每課固定 5 個步驟：
  1. 修辭教學
  2. 看例句
  3. 找線索
  4. 選答案
  5. 闖關
- 一次呈現一題，降低畫面負荷。
- 答錯先提供判斷提示，可再次作答。
- 例句與題目可使用瀏覽器朗讀功能。
- 每課學習進度會儲存在目前瀏覽器的 localStorage 中。
- 保留「修辭總整理」與跨課「總闖關」。

## 課程內容

1. 時間是什麼
2. 妙用便利貼
3. 提早五分鐘
4. 水滾了
5. 為梨花撐傘
6. 小鉛筆大學問

修辭類型包括：譬喻、轉化、類疊、映襯、設問、排比、摹寫、感嘆、層遞、頂真。

## 建立自己的 GitHub Pages

1. 登入 GitHub。
2. 建立一個新的 Public repository，例如：`rhetoric-detective-hanlin`。
3. 將本資料夾中的 `index.html` 上傳到 repository 根目錄。
4. 進入 `Settings` → `Pages`。
5. `Build and deployment` 選擇 `Deploy from a branch`。
6. Branch 選 `main`，資料夾選 `/root`，按 `Save`。
7. 等待 GitHub Pages 完成部署後，即可使用自己的網址。

網址通常會是：

`https://你的GitHub帳號.github.io/rhetoric-detective-hanlin/`
